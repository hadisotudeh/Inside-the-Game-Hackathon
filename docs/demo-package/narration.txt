Touchline helps football fans and commentators follow a match with statistics and AI explanations.

Open this Azure address to try it yourself. No installation is needed. The pitch shows recorded actions in place of broadcast footage.

We use event data: individual passes, shots, and other actions, each with a time, player, and location. This historical Chelsea against Arsenal match simulates live play by streaming one event at a time. Charts and AI use only the events revealed so far.

At fifteen times speed, match evidence builds quickly. Watch the clock, statistics, and charts update as each event arrives.

Select a shot to inspect the chance. The momentum chart compares recent attacking threat, using an expected threat proxy. Its timeline grows with the match. Passing networks show which players connect.

Narration adds short, timestamped match notes automatically. It follows the evidence as play develops, so you can watch without typing a question.

Switch to Ask the match for a specific question: who has created the better chances? Answers use the current match snapshot. Switching modes keeps your notes and conversation.

Historical events enter FastAPI one at a time. Its analytics update browser charts through a live event stream. For narration and questions, Microsoft Agent Framework runs three tools: match statistics, recent events, and player summaries. Azure GPT four point one mini explains that evidence. The server checks the answer format and event references before sending it to the browser.
